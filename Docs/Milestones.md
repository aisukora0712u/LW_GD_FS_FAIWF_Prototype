# 生产阶段门禁

## Foundation（第 1–2 周）

退出条件：仓库、LFS、程序集、固定 Unity、PR 门禁、构建信息和自动测试可重复执行。

## Core Pipeline（第 3–6 周）

退出条件：平台抽象、存档、输入、场景流、Addressables、导入校验与 Windows 构建能支撑真实玩法。

## Vertical Slice（第 7–10 周）

退出条件：一个最终质量关卡贯穿策划、美术、玩法、音频、本地化、存档、Steam、性能和发布链路；目标硬件性能与制作吞吐量达到批准预算。

未达到垂直切片退出条件不得转入大规模内容生产。

## Production

一至两周迭代、每日可玩构建、每周团队体验、里程碑完整回归。持续跟踪构建成功率、PR 周期、缺陷逃逸率、崩溃率和关卡性能。

## Release

功能冻结后只接受缺陷修复；内容冻结后资产变化需发布负责人批准。完成干净安装、旧存档、Steam 分支、回滚、符号与商店合规演练后才可签署 RC。
