# 质量与性能策略

## 自动化层级

- EditMode：纯逻辑、配置、状态机、存档校验与迁移、编辑器工具。
- PlayMode：Bootstrap、场景流、暂停、输入切换和玩家关键路径。
- 确定性模拟：固定策略与种子范围执行完整 Run，阻断卡死、全胜/全败等极端回归，并保存 JSON 指标。
- Player 冒烟：启动、新游戏、存档、读档、完成关卡、菜单、退出。
- 发布回归：干净安装、离线 Steam、Overlay、云存档冲突、旧版本升级和 Steam Deck。

PR 必须通过仓库策略、EditMode、项目内容校验、确定性平衡门、Development Player 和 PlayMode。每日构建保存 30 天；正式标签只从干净环境构建一次。

## 初始性能门槛

- 最低配置、1080p、低画质目标 60 FPS，以 P95 帧时间验收。
- CPU 和 GPU 帧预算分别以 16.6 ms 为硬上限，实际内容预算应保留平台和波动余量。
- 正常游玩禁止持续 GC Alloc；加载分配必须有测量记录。
- 垂直切片结束时冻结最低配置、内存峰值、包体和加载时间门槛。

性能回归必须附 Unity Profiler 或平台分析器捕获，不能仅凭编辑器 Game View 结论。

## 人工兼容矩阵

覆盖键鼠、Xbox 类手柄、PlayStation 类手柄、断连重连、常用宽高比、窗口/无边框/全屏、多显示器、无音频设备、低磁盘空间、损坏存档和 Steam 离线模式。
