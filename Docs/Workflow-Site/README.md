## 打开

推荐在仓库根执行：

```powershell
node Tools/Preview-Workflow.mjs
```

然后打开终端打印的本地地址。服务器仅监听 `127.0.0.1`；站点资源和页面引用的原文使用明确白名单。可用 `--port 4174` 指定其他端口；Ctrl+C 停止。也可尝试直接双击 `dist/index.html`：相对资源已静态检查，但本轮浏览器工具禁止访问 `file:` URL，因此直接打开方式未作浏览器实测。

页面是人工整理的仓库快照，不是实时 CI 仪表盘。更新依据、测试结果和结论时同步修改 `dist/report-data.js` 与 `dist/index.html`。无安装、编译或联网要求。
