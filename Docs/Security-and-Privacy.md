# 安全、隐私与依赖治理

- 禁止提交 Steam 凭据、App 密钥、Sentry DSN 私密部分、`.env`、`config.vdf` 和个人数据。
- GitHub Actions 使用最小权限；Steam 发布使用带人工审批的 Environment。
- 第三方包必须登记版本、来源、许可证、维护者、数据行为和升级/移除方案。
- 玩家诊断默认最小化，只包含版本、硬件摘要、异常栈和必要上下文；提供清晰开关与隐私说明。
- 不采集玩法遥测，不将崩溃信息用于玩家画像。
- 发现密钥泄漏时先撤销和轮换，再清理历史；禁止只删除最新提交。

正式接入崩溃服务需要新增 ADR，明确符号保留、数据区域、保留周期、用户同意和离线失败行为。

## AI 内容治理

- 候选包只记录原始提示词的 SHA-256，不提交可能含个人数据、密钥或受限素材的提示词正文。
- 来源记录必须声明生成器、模型、来源、许可和负责人；字段缺失直接阻断审阅。
- AI 生成者不得填写人工 reviewer、伪造批准时间或把候选状态改为 approved。
- 批准绑定候选四个源文件的摘要；任何字节变化都使批准失效。
- 晋级前重新执行解析、本地化覆盖和固定种子模拟，且要求 active baseContentVersion 未漂移。
